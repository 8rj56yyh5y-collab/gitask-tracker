# Как открыть D&N на iPhone

## Способ 1. С MacBook по Wi-Fi — проще всего, для теста

Работает, пока MacBook включён и iPhone в той же Wi-Fi сети. Telegram и Monobank в этом режиме
не подключатся (им нужен адрес в интернете), Apple Pay и всё остальное — можно пробовать.

1. На MacBook установите **Node.js** с https://nodejs.org (кнопка **LTS**), если ещё не стоит.
2. Скачайте проект: на GitHub откройте репозиторий, **Code → Download ZIP**, распакуйте.
3. В папке дважды нажмите **`start-mac.command`**.
   Если macOS напишет, что разработчик не подтверждён: правой кнопкой по файлу → **Открыть** → **Открыть**.
4. Через пару минут в окне появится адрес вида `http://192.168.1.25:3000` и **пароль**.
5. На iPhone откройте этот адрес в Safari, введите пароль.
   «Поделиться» → **«На экран „Домой“»** — появится иконка D&N.

Остановить — закрыть окно Терминала. Данные сохраняются в папке `data` на Mac.
Демо-данных нет: база пустая, только стандартные категории. Хотите посмотреть с примерами —
в Терминале в папке проекта: `npm run demo`.

## Способ 2. Постоянно, из любого места — Render (кнопка)

1. Нажмите кнопку **Deploy to Render** в README (или откройте
   `https://render.com/deploy?repo=https://github.com/8rj56yyh5y-collab/gitask-tracker`).
2. Войдите через GitHub, разрешите доступ к репозиторию `gitask-tracker`.
3. Render покажет готовую настройку и спросит **пароль для входа** (`DN_APP_PASSWORD`). Введите — **Apply**.
4. Через несколько минут появится адрес вида `https://dn-xxxx.onrender.com` — его открыть на iPhone.

Постоянный диск для базы есть только на платном плане Render (около $7 в месяц).
Этот способ ещё не проверен на реальном развёртывании — если на каком-то шаге ошибка, пришлите её текст.
