ШАГ 1

Внизу «Карты»

  1. Лимит по умолчанию: впишите, например, 30000 → «Сохранить». Он поставится каждой карте.
  2. Добавить карту: выберите банк и впишите последние 4 цифры.
  3. «Добавить». Повторите для каждой карты: Радабанк, Альянс, ПУМБ, Приват, А-Банк, NovaPay.

ШАГ 2 · ЕСЛИ У БАНКА НЕСКОЛЬКО КАРТ

Объединить в одну основную

У Monobank несколько карт, а лимит один. На странице «Карты» появится блок «объединить в одну?»:

  1. Выберите основную карту.
  2. «Объединить». Останется одна плитка, внутри видно траты каждой карты.

Подключить в D&N

  1. D&N → Ещё → Настройки → Уведомления в Telegram → вставьте токен → «Подключить».
  2. «Открыть бота и нажать Старт» → в Telegram Start. Бот ответит «Готово ✓».

ШАГ 5

Токен с api.monobank.ua

  1. Откройте api.monobank.ua, войдите через приложение Monobank, скопируйте токен и вставьте в D&N.
  2. «Вести операции с»: оставьте сегодня, тогда старые операции не подтянутся.
  3. «Подключить». Карты Monobank добавятся сами, и каждая операция будет приходить в Telegram.

ЧАСТЬ 4 iPhone: «Команды» — для всех остальных банков

Apple не даёт программам видеть оплаты. Это делает встроенное приложение «Команды» (Shortcuts): после каждой оплаты Apple Pay оно отправляет сумму, магазин и карту в D&N. Работает с любой картой из Wallet.

Не ищите D&N в «Командах»Его там нет и не будет. Связь — через ссылку из настроек D&N.
Не вставляйте ссылку в поискПоиск ищет действия по названию. Ссылка вставляется в голубое слово «URL».
Не заходите в «Подробнее → Вопросы импорта»Это для пересылки команды другим. Все настройки — прямо в действии.

ШАГ 14

Оплатите что-нибудь телефоном

Через несколько секунд в Telegram придёт сообщение: сумма, магазин и карта, определённая сама.

  1. Нажмите категорию. Если у неё есть подпункты (стрелка ›), откроется следующий список.
  2. Выберите подпункт или «✓ Просто «Категория»». Готово, записано.
Не успели? Операция ждёт в D&N красным блоком «Нужно записать» в «Истории», пока вы её не разнесёте.

ЕСЛИ НИЧЕГО НЕ ПРИШЛО

Проверьте по порядку

  1. В «Командах» → «Автоматизация» откройте её: стоит «Немедленный запуск»?
  2. В действии Метод POST, Тело JSON и три поля (amount, merchant, card)?
  3. Операция появилась в D&N в «Истории», но не в Telegram? Тогда переподключите Telegram в «Настройках».
  4. Сайт открывается? Сразу после обновления Render 1–3 минуты показывает ошибку 502, это нормально.
