# D&N для iPhone — как собрать и отправить в Apple

Приложение лежит в папке `ios-app/`. Внутри — тот же D&N, что на сайте (данные на сервере),
плюс то, чего нет в браузере: вход по **Face ID**, работа на весь экран, своя иконка и заставка.

Нужно один раз: **Mac**, **Xcode** и **аккаунт разработчика Apple** ($99 в год).

---

## Шаг 1. Аккаунт разработчика Apple (можно начинать сразу)

1. На iPhone поставьте приложение **Apple Developer** из App Store.
2. Откройте его → **Account** → войдите своим Apple ID (нужна двухфакторная защита — обычно она уже включена).
3. Нажмите **Enroll Now** → выберите **Individual** (частное лицо) → подтвердите личность по фото документа.
4. В конце Apple попросит оплатить **$99**. Платите здесь же, картой. Без оплаты аккаунт не активируется.
5. Обычно аккаунт включается за 1–2 дня — придёт письмо «Welcome to the Apple Developer Program».

## Шаг 2. Подготовить Mac (пока ждёте письма)

1. Mac App Store → **Xcode** → «Загрузить» (около 10 ГБ, может идти час).
2. Откройте Xcode один раз, согласитесь с условиями, дождитесь установки компонентов.
3. Xcode → **Settings → Accounts** → «+» → **Apple ID** → войдите тем же Apple ID.
4. Поставьте **Node.js** (https://nodejs.org → кнопка LTS), если его ещё нет.

## Шаг 3. Открыть проект

В «Терминале» на Mac (по очереди):

```bash
git clone https://github.com/8rj56yyh5y-collab/gitask-tracker.git
```

```bash
cd gitask-tracker/ios-app && npm install && npx cap sync ios
```

```bash
npx cap open ios
```

Откроется Xcode с проектом **App**.

## Шаг 4. Подписать приложение

1. Слева нажмите на синий значок **App** → вкладка **Signing & Capabilities**.
2. Поставьте галочку **Automatically manage signing**.
3. **Team** — выберите своё имя (появится после шага 1).
4. Если Xcode скажет, что идентификатор `com.dnmoney.app` занят, — поменяйте на свой, например `com.<ваше-имя>.dn`
   (тот же поменять в `ios-app/capacitor.config.ts` → `appId`).

## Шаг 5. Проверить на своём iPhone

1. Подключите iPhone кабелем, наверху Xcode выберите его в списке устройств.
2. Нажмите ▶ (Run). На iPhone: **Настройки → Основные → VPN и управление устройством** → доверять разработчику.
3. D&N откроется как приложение и спросит Face ID.

## Шаг 6. Отправить в TestFlight

1. Наверху Xcode выберите устройство **Any iOS Device (arm64)**.
2. Меню **Product → Archive**. Через пару минут откроется окно **Organizer**.
3. **Distribute App** → **App Store Connect** → **Upload** → дальше всё по умолчанию.
4. Откройте https://appstoreconnect.apple.com → **Apps** → «+» → **New App**:
   имя **D&N** (если занято — например, «D&N — учёт денег»), язык — русский, Bundle ID — тот же, что в шаге 4.
5. Через 10–30 минут сборка появится во вкладке **TestFlight**.
6. **Internal Testing** → «+» → добавьте себя. На iPhone поставьте **TestFlight** из App Store — D&N появится там.

Чтобы дать D&N другим людям: **TestFlight → External Testing** → создать группу → включить **Public Link**.
Первую внешнюю сборку Apple проверяет (обычно до суток).

---

## Обновления

Почти всё меняется **на сервере** — приложение подхватывает новую версию D&N само, ничего пересобирать не нужно.
Пересобирать (шаги 3 и 6) нужно, только если поменялась иконка, название или что-то в папке `ios-app/`.
Перед новой сборкой увеличьте номер: Xcode → App → **General → Version / Build**.
