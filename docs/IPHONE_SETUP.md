# Настройка iPhone: запись после каждой оплаты

D&N ловит платежи через приложение **«Команды»** (Shortcuts), которое есть на каждом iPhone.
Нужно один раз создать две автоматизации. В примерах `https://ВАШ-ДОМЕН` — адрес D&N,
`КЛЮЧ` — значение `DN_INGEST_TOKEN` с сервера.

## 0. Поставить D&N на экран «Домой»

Safari → открыть `https://ВАШ-ДОМЕН` → «Поделиться» → «На экран „Домой“».

## 1. Apple Pay → сразу экран «Куда ушли деньги?»

Требуется iOS 17 или новее.

1. «Команды» → вкладка «Автоматизация» → «+» → **«Транзакция»**.
2. Карты: выбрать все карты в Wallet. Категории: все. → «Запускать немедленно».
3. Новая пустая команда, добавить действия:
   1. **«Получить содержимое URL»**
      - URL: `https://ВАШ-ДОМЕН/api/ingest`
      - Метод: `POST`
      - Заголовки: `Authorization` = `Bearer КЛЮЧ`
      - Тело запроса: JSON
        - `source` = `applepay`
        - `amount` = переменная «Ввод команды → Сумма»
        - `merchant` = переменная «Ввод команды → Продавец»
        - `card` = переменная «Ввод команды → Карта или пропуск»
   2. **«Получить значение словаря»** → ключ `url` из результата.
   3. **«Открыть URL»** → значение словаря.

После оплаты телефон сам откроет D&N на экране выбора подразделения.

> Чтобы карта определялась автоматически, в D&N на странице «Лимиты» добавьте карту
> с теми же последними 4 цифрами, что и в Wallet.

## 2. SMS от банка → операция в очередь «Не разнесено»

Подходит для любых банков, где включено SMS-информирование (ПУМБ, ПриватБанк, А-Банк, Радабанк, Райффайзен).

1. «Автоматизация» → «+» → **«Сообщение»**.
2. Отправитель: выберите номера/имена банков (например, `PrivatBank`, `PUMB`). → «Запускать немедленно».
3. Действия:
   1. **«Получить содержимое URL»** — как выше, но JSON:
      - `source` = `sms`
      - `text` = переменная «Ввод команды → Содержимое»
   2. По желанию — «Получить значение словаря» `url` → «Открыть URL».

Если в SMS нет суммы (например, код подтверждения), D&N такое сообщение пропускает.

## 3. Monobank — полностью автоматически

1. Получить личный токен: https://api.monobank.ua/ (вход через приложение Monobank).
2. Зарегистрировать вебхук (один раз, с компьютера):

```bash
curl -X POST https://api.monobank.ua/personal/webhook \
  -H "X-Token: ТОКЕН_MONOBANK" \
  -d '{"webHookUrl":"https://ВАШ-ДОМЕН/api/monobank?key=КЛЮЧ"}'
```

3. Узнать ID счетов: `curl -H "X-Token: ТОКЕН_MONOBANK" https://api.monobank.ua/personal/client-info`
   и вписать нужный `id` в поле «ID счёта Monobank» у карты в D&N.

## Проверка без телефона

```bash
curl -X POST https://ВАШ-ДОМЕН/api/ingest \
  -H "Authorization: Bearer КЛЮЧ" -H "Content-Type: application/json" \
  -d '{"source":"applepay","amount":"₴250,00","merchant":"АТБ","card":"ПриватБанк •••• 1234"}'
```
