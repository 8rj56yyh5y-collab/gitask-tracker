# D&N в Claude

Версия D&N, которая работает прямо в Claude (страница-артефакт): https://claude.ai/artifact/59EW5rN5Hoz5PH4eKV141c

Данные хранятся в хранилище артефакта (операции, категории, карты, продажи и ставки комиссий), ИИ-разбор идёт через Claude зрителя.
Автоматического приёма операций (Apple Pay, Monobank, Telegram) здесь нет — для этого нужна серверная версия из корня репозитория.

## Продажи

- Ставки комиссий по группам товаров: процент отделу продаж и процент маркетплейса; лист можно вставить текстом — Claude разберёт его.
- Новая продажа: группа определяется по ключевым словам, иначе — через Claude; канал «вживую» или «маркетплейс»;
  комиссия отделу считается от суммы продажи или от суммы после маркетплейса (настройка).
- Ставки запоминаются в каждой продаже. Поступление за продажу можно сразу записать в учёт денег.
