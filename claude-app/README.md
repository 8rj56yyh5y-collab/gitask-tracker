# D&N в Claude

Версия D&N, которая работает прямо в Claude (страница-артефакт): https://claude.ai/artifact/59EW5rN5Hoz5PH4eKV141c

Данные хранятся в хранилище артефакта (операции, категории, карты), ИИ-разбор идёт через Claude зрителя.
Автоматического приёма операций (Apple Pay, Monobank, Telegram) здесь нет — для этого нужна серверная версия из корня репозитория.
